# BuildCostIQ 岗位角色操作手册

版本：`v0.8.0-rc5`

## 使用方法

登录后首页只显示当前岗位的工作面和本岗位手册。每次操作按四句话复述：

1. **输入什么**：资料、任务、位置、时间和责任人是否明确；
2. **保存什么**：只保存本岗位形成的事实和证据；
3. **交给谁复核**：提交对应责任线或专业负责人；
4. **还缺什么**：发现缺来源、缺签认、口径冲突或异常，先退回，不猜测补齐。

## 岗位快速流程

| 岗位 | 先做什么 | 保存成果 | 完成边界 |
|---|---|---|---|
| 项目经理 | 看经营看板和四类结果池 | 责任、决策、确认、经营处置 | 只处理升级事项，不代填专业事实 |
| 造价经理 | 建立项目并接入合同、清单、图纸 | P01–P08 造价事实、证据和审核结果 | 金额必须有来源、口径和人工确认 |
| 造价员 | 核对编码、单位、数量和造价资料 | P02/P04/P05/P06/P07 造价基础 | 不改技术结论、现场事实和责任线 |
| 技术负责人 | 核对图纸版本和技术条件，拆分分包工作包 | P03 图纸、分包方案审查、技术交底、P06 技术变更和技术证据 | 没有图纸版本、方案确认和交底，不进入分包实施 |
| 生产经理 | 接收技术放行，编制分包计划并组织资源 | 分包计划、资源、实物量、纠偏和移交记录 | 没有技术放行、责任人和资源计划不下达；完成量未复核不关闭 |
| 施工员/测量员 | 记录位置、WBS、时间和现场事件 | 现场事实、完成量、基础实测 | 原始事实只追加，不覆盖历史 |
| 测量员 | 核对控制点、图纸版本和测量范围 | 放样、坐标、标高、实测工程量 | 不用口头结论替代实测 |
| 质量负责人 | 接收报验并检查工序和检验批 | 检查、整改、复验、验收结论 | 没有整改和复验依据不得放行 |
| 试验检测员 | 核对进场批次和取样计划 | 取样、试验报告、检测台账 | 报告缺批次或位置就标记异常 |
| 资料员 | 检查文件、版本和签认完整性 | 报验资料、版本台账、证据包、数字资产 | 只归档，不制造业务事实 |
| 安全员 | 巡检并记录隐患责任人和期限 | 检查、隐患、整改复查、安全验收 | 隐患必须有责任人、期限和关闭证据 |
| 采购员 | 引用确认的造价基准和采购需求 | 询价比价、订单、供应商、到货记录 | 不改造价基准，偏差提交确认 |
| 仓管员 | 核对到货批次、验收状态和领料单 | 入库、出库、退库、库存、盘点 | 只处理收发存，不进入 P04 |
| 行政人员 | 确认项目经理对当前项目的授权 | 项目人员名册、授权、交接留痕 | 无授权不增删人员或改岗位 |

## 造价核心责任链

造价是项目经营结果的商业主线，但不替代技术、生产和现场专业事实。三条责任线在同一条成果链上交接：

```text
项目经理：决策、资源、升级与经营处置
   ↓ 下达目标/确认优先级
技术负责人：技术边界、方案审查、交底、技术放行
   ↓ 技术放行/接口条件
生产经理：计划、资源、分包组织、实物量兑现
   ↓ 完成量/移交记录
施工员·测量员·质量·试验：现场事实与实体验收
   ↓ 可核验的工程量与验收证据
造价员：编码、量价基础、零号台账与过程资料
   ↓ 有来源的计量基础
造价经理：商业总审、计量、变更、结算初审与成果确认
   ↓ Outcome/经营异常
项目经理：经营决策、纠偏资源与跨线升级闭环
```

执行规则：

- 项目经理拥有决策和升级权，但不能代改技术、生产、现场或造价事实；
- 技术负责人和生产经理是并行责任线：技术负责人决定“能不能做、按什么标准做”，生产经理决定“何时做、用什么资源兑现”；
- 造价经理是商业总审人，所有金额必须回到 P01–P08 的原始来源、版本、证据和人工确认；
- 造价员只形成可追溯的量价基础，不能替代技术结论、现场完成量或责任线确认；
- 任何冲突回到 `Event → Evidence → Verification → Outcome`，由对应责任线负责人确认，不能用口头指令覆盖历史。

系统通过 `/api/line-contracts` 发布每个岗位的输入、输出、下一接收岗位、升级对象和不可修改项；WebUI 只展示当前登录岗位的交接卡片。

## 分包管理双线工作流

分包不新增独立金额事实源，沿用现有 `Core Event → Evidence → Verification → Outcome` 和组织协同界面留痕。

### 技术负责人：技术线

```text
拆分分包工作包
  → 审查分包方案、专项措施和样板/首件
  → 完成图纸会审、技术交底和接口确认
  → 技术核定/变更人工确认后技术放行
  → 按技术标准验收并交质量、资料、造价线关联
```

### 生产经理：生产线

```text
接收技术放行
  → 排分包计划、接口顺序和人员机料资源
  → 按 WBS/位置跟踪实物量、质量安全接口和偏差
  → 建立协同任务推动整改/变更并记录人工确认
  → 完成量交测量、质量、造价线复核，归档后关闭
```

技术负责人只负责技术边界和放行，生产经理只负责计划、资源、现场兑现和移交；争议回到工程事件，不用口头指令替代记录。

## 人员新增

项目经理或已获项目经理授权的行政人员，在当前项目的“人员管理”中填写**姓名/登录名 + 岗位角色**，保存后把一次显示的初始密码交给本人。人员直接用姓名和密码登录，不需要自行注册。每个项目的人员名册独立维护；在一个项目新增、移除或合并岗位，不会改变其他项目。

## 统一成果链

```text
Project → WBS → Location → Event → Evidence → Verification → Outcome
```

P01–P08 保存专业事实，P09 只从已有事实派生经营结果，不建立第二金额事实源。
